# 页面性能与 404 更新

本次优化保留首页星系和三维书架，减少持续绘制与图片传输开销。

- 14 张壁纸增加 WebP 版本，最长边 1920 px，质量 80。原图合计 6,577,961 字节，WebP 合计 2,258,176 字节，减少 65.7%。这是资源集合的体积对比，不是单次首屏下载量或加载时间。
- 构建器优先使用 WebP，缺少时回退原图。重新生成：`python tools/optimize-web-assets.py`（需要 Pillow）。
- 图谱默认关闭自动巡航，交互结束、镜头和弹簧收敛后停止刷新；离屏和后台暂停。仍可手动打开巡航。
- 首页星系限制约 30 帧每秒；降低粒子数和画布像素密度，移动端及低配置设备进一步降级。该值是调度上限，不代表设备实测帧率。
- 自定义鼠标追踪位置收敛后停止请求动画帧。页面后台暂停 CSS 动画；降低大面积模糊开销。
- 主题样式使用构建版本参数，版本计算包括站点配置，减少更新后读取旧样式的情况。
- 404 改为 SVG 机器人与三信标收集互动，事件驱动，无持续 JavaScript 绘制循环。支持键盘操作、重玩、减少动态效果偏好及离屏暂停。

验证：构建、自检和站内资源检查通过（66 个 HTML，3355 条引用）。浏览器验证 404 收集与重玩、图谱星云布局和 DDS 搜索通过，未发现脚本错误。

以上为本地构建及浏览器验证，未执行线上发布，也没有把资源缩减比例当作线上速度提升比例。部署时需包含生成的 WebP 和完整 public 产物。
