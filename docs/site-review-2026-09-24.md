# 博客内容与阅读体验修订

## 壁纸主题

从用户指定的 Wallpaper Engine 目录 `3168117211` 导入「bocchi the rock 孤独摇滚 波奇酱 光晕」，新增主题 **波奇光晕 / Bocchi Halo**。粉色与青色点缀搭配深蓝底色，支持静态 WebP 与无声动态背景，保留原默认主题。

保留完整 20 秒循环，视频从 18,687,103 字节压缩到 1,572,093 字节（约减少 91.6%），输出 1920 宽、24 fps、H.264、faststart。源壁纸未修改。浏览器检查了主题切换、静态图和动态视频加载。

## 首页与后台

首页三项统计支持鼠标悬浮与键盘聚焦查看说明。后台「站点设置」可编辑数值、名称与悬浮提示；`{posts}`、`{projects}` 等已知计数变量继续自动计算，普通大括号文本不会再导致构建失败。空提示不生成提示按钮。

后台在初始数据尚未返回时打开站点设置，会提示等待，避免读取空状态导致报错。已通过后台保存并核对提示内容持久化。

## UI 与格式

- 文章正文遵守用户选择的阅读宽度；标题在小屏缩放，段落与标题层级保持一致。
- 文章、项目和普通页面新增手机折叠目录，选择目录项后收起。
- 表格保持局部横向滚动，支持键盘聚焦，移除正文表格的背景模糊。
- 示例画布保持宽高比，手机页面没有整体横向溢出。
- 设置面板不再写死字体包体积或所有视频的分辨率。

## 内容范围

修订 7 篇文章与 5 个项目页。主要修正 DDS 交付语义、共享内存与零拷贝的区别，MPC/WBC 的约束和参考接口，阻抗控制量纲，RL 导出一致性与因果判断，实时统计口径以及旧步态示例。

git-vis 根据公开仓库 README 补齐功能、启动方式、命令预览机制与支持范围，移除占位内容。其他项目移除指向 GitHub 首页的假仓库入口。原始文章与项目记录保存在 `docs/review-baseline/`，不参与站点发布。没有原始日志支持的性能表从公开正文移出，改为说明可复核的测试条件；未编造机器人实测数据。

可运行示例标明教学数据，修正负超调与调节时间统计，将交互计算从重复扫描改为线性扫描；纠正 sandbox iframe 必然独立进程的表述。
