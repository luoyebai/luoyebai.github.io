# 什么是编程


--

把一个问题写成明确的规则，并让计算机重复执行。


--

本课目标：解释程序的输入与输出；把需求拆成步骤；用测试判断结果。

----
## 先把问题说清楚


--

例子：统计一组温度中的最高值。


--

| 约定 | 本例的选择 |
|---|---|
| 输入 | 一个有限的数值序列，单位为摄氏度 |
| 输出 | 最大值，仍使用摄氏度 |
| 空序列 | 返回 `None`，不假装最大值为 0 |
| 非数值 / NaN | 本课不接收；实际接口应校验 |


--

先约定边界，代码才有明确的对错标准。

----
## 程序由什么组成


--

- **数据**：温度列表、名字、时间戳。

--

- **状态**：当前读到哪里、目前找到的最大值。

--

- **控制流**：顺序执行、条件分支、重复循环。

--

- **接口**：输入从哪里来，结果交给谁。


--

算法描述解决问题的方法；程序还需要处理输入、错误、资源和运行环境。

----
## 图灵机在讨论什么


--

图灵机是一种计算模型：读写头读取纸带符号，依据当前状态和转移规则，写入符号、移动并切换状态。


--

它帮助我们讨论“什么可以计算”，不是现代电脑内部结构的施工图。


--

- **可计算性**：有没有算法能解决这一类问题？

--

- **复杂度**：输入变大后，时间与空间如何增长？

--

- **工程实现**：在当前机器和限制下，如何做得可靠？


--

这三个问题相关，但不能互相替代。

----
## 如何编程：先写步骤


--

对非空序列：


--

1. 把第一个值当作当前最大值。

--

2. 依次读取后续值。

--

3. 如果新值更大，就更新最大值。

--

4. 读完后返回结果。


--

循环中的不变量：当前最大值始终等于**已读部分**的最大值。


--

每个元素比较一次，时间复杂度 O(n)，额外空间 O(1)。

----
## 一个完整实现


--

Python 3，保存为 `maximum.py`：


--

```python
def maximum(values):
    it = iter(values)
    best = next(it, None)
    if best is None:
        return None
    for value in it:
        if value > best:
            best = value
    return best

assert maximum([18, 25, 21]) == 25
assert maximum([-8, -2, -5]) == -2
assert maximum([7]) == 7
assert maximum([]) is None
print('4 cases passed')
```


--

在终端运行 `python3 maximum.py`。实际项目可直接使用内置 `max`。

----
## 为什么“跑起来了”还不够


--

- 语法正确：解释器能够解析。

--

- 行为正确：结果符合输入输出约定。

--

- 边界正确：空输入、负数、重复值不会破坏约定。

--

- 可维护：别人能理解变量、接口与错误信息。


--

如果初始化 `best = 0`，正数样例能通过，但全负数样例会失败。
测试不等于一般性的证明，却能把发现过的错误变成长期检查。

----
## 练习与参考答案


--

**练习**：扩展函数，同时返回最大值出现的第一个位置。空输入仍返回 `None`。


--

**思路**：保存 `(位置, 值)`；仅在 `value > best` 时更新，使用 `>=` 会选择最后一个位置。


--

验证：`[3, 8, 8] → (1, 8)`；`[-3] → (0, -3)`；`[] → None`。
