## Trot 的相位关系

对角腿成组交替，例如左前与右后同相，另一组相差半个周期。支撑相占空比决定一条腿在周期中被计划为支撑的时间比例，但计划接触与实际触地可能不一致。

| 参数 | 改变什么 | 需要一起观察 |
|---|---|---|
| 周期 | 支撑与摆动的时间尺度 | 驱动速度、冲击、跟踪误差 |
| 占空比 | 支撑时间比例 | 接触重叠、力分配和滑移 |
| 步幅 | 单周期的水平运动范围 | 关节可达性与速度限制 |
| 抬脚高度 | 摆动净空 | 地形、关节行程与落地速度 |
| 身体高度 | 腿部姿态与工作空间 | 力矩余量、奇异位置 |

## 轨迹示例：从相位生成足端位置

以下 Python 3 示例仅生成二维几何轨迹，**不是完整步态控制器**。相位已经归一化到一个周期，周期时长由调用方用于计算相位。示例在摆动端点使用零斜率形状，仍需按实际运动需求处理支撑与摆动切换的速度连续性。

```python
import math

def trot_trajectory(phase, stride=0.12, height=0.06, duty=0.55):
    if not all(math.isfinite(v) for v in (phase, stride, height, duty)):
        raise ValueError('参数必须有限')
    if not 0.0 < duty < 1.0 or height < 0:
        raise ValueError('占空比需在 0 与 1 之间，高度非负')
    phase %= 1.0
    if phase < duty:
        s = phase / duty
        return stride * (0.5 - s), 0.0
    s = (phase - duty) / (1.0 - duty)
    smooth = s * s * (3.0 - 2.0 * s)
    return stride * (smooth - 0.5), height * math.sin(math.pi * s) ** 2

for phase in (0.0, 0.275, 0.55, 0.775, 1.0):
    print(phase, trot_trajectory(phase))
```

足端坐标还需要经过坐标变换、逆运动学、限位和驱动接口才能执行。若要限制冲击，应进一步设计完整的速度、加速度轨迹，而不是只检查位置曲线是否平滑。

## 比调参数更早的检查

**零位与方向。** 核对编码器方向、关节顺序、零位与连杆参数。零位标定应使用该硬件支持的方法；不要把撞机械限位当成通用标定手段。

**接触判定。** 电流、关节速度、足端力等信号受惯性、摩擦与滤波影响。单个固定阈值通常不足以覆盖全部动作，接触状态需要迟滞、时序与异常处理。

**驱动余量。** 电压变化会影响可达转速、功率与饱和行为。在电流闭环未饱和且力矩常数近似不变时，不能简单断言同一实际电流因电池电压下降就必然产生更小力矩。

**机械误差。** 回差、弹性变形与腿长差异应尽量通过测量和模型校正定位。仅调整身体高度可能掩盖不对称，而不是消除原因。

## 一次只改一个因素

固定初始姿态、地面、负载和测试时长。每次记录参数版本、足端跟踪误差、关节饱和、机体姿态和失败时刻。用相同条件重复试验，才能区分参数作用与偶然接触差异。

没有给出作用点和持续时间的“最大侧推力”，或没有表面材料的“通过坡度”，都不适合跨平台比较。因此这里保留分析方法，不把早期性能数字作为当前能力承诺。
